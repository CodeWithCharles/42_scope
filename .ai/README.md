# Memoire Projet

Ce dossier sert de base de continuite pour reprendre `scop` sur n'importe quel PC sans dependre d'un gros historique de chat.

## Ordre de lecture au demarrage

1. `bootstrap.md`
2. `active_state.md`
3. `project_context.md`
4. `decisions.md`

## Role des fichiers

- `bootstrap.md` : point d'entree court pour une nouvelle session
- `active_state.md` : etat courant, prochains pas, blocages
- `project_context.md` : architecture stable du projet
- `decisions.md` : decisions durables et leurs raisons
- `skills/` : skills projet versionnees avec le repo
- `sessions/` : notes de session si besoin, facultatif

## Regle simple

Les skills globales vivent dans `Codex_Agentic`.  
Les fichiers `.ai/` conservent l'etat vivant de ce repo.  
Git transporte le tout entre machines.
